# v2.6.0 pre-push review

Scope: the staged yoyo changes on `main`, with an annotated `v2.6.0` tag.
The nested Codex study checkout is excluded. GitHub releases and PyPI uploads
are separate from this source/tag push.

1. **Fragile logic:** `internal/agent/afk.go:AFKContinuation` and
   `internal/proxy/proxy.go`'s AFK submit case infer readiness from terminal
   text and cursor state. They deliberately require recognized layouts and
   exact draft echo; missing evidence cancels submission.
2. **Assumptions and blind spots:** real installed Codex/Claude conversations,
   custom footers, keymaps and terminal timing are not comprehensively tested.
   Unknown layouts abstain, and AFK stays disabled by default.
3. **User impact:** the default delay becomes 1 second; explicit CLI/agent/global
   configuration remains authoritative. Opt-in AFK now handles simple continuation
   questions once per context instead of repeatedly nudging any idle screen.
   There is no persisted data migration or new dependency.
4. **Likely failure path:** an unrecognized composer or missing echo requires
   manual input and can leave the pasted draft visible. Codex approval matching
   similarly abstains on incomplete or ambiguous menus; automated operation may
   pause until the user responds.
5. **Recovery controls:** `Ctrl+Y a` disables AFK; `Ctrl+Y 0` switches approval
   to manual; `-delay 3` restores the previous delay. The existing `v2.5.3` tag
   remains available for rollback; no old tag or history is rewritten.
6. **Checks:** full race run passed 502 test/subtest events across 11 packages,
   with no failures, skips or races. Vet, whitespace checks, four target builds
   and native `yoyo v2.6.0` output passed. A repeated tmux fixture timeout was
   addressed by isolating shell/config startup, with the failing cases passing
   three runs and the final whole suite passing. Live CLI canaries remain a
   stated limit, especially before broader AFK enablement.

Counter-evidence considered (confidence that the unverified failure occurs):

- A future CLI layout could resemble an eligible continuation screen but bind
  Enter differently: **2/5**; limited by opt-in AFK, exact echo and cancellation.
- A slow renderer could miss the 2-second echo window: **2/5**; submission is
  cancelled and the attempted question is not repeatedly injected.
- Host terminal setup could still cause integration-test timing failures:
  **1/5** after configuration isolation, three focused passes and a full race pass.

Verdict for this authorized source/tag push: **▶︎▶︎PUSH▶︎▶︎**.
This does not assert universal CLI compatibility or completion of an artifact release.
